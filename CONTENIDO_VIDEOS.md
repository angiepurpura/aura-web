# AURA — Biblioteca de vídeos para redes sociales

Guía lista para usar con cualquier herramienta de generación de vídeo por IA
(ej. la función de vídeo de Sora, Runway, Pika, o similares). No necesitas
saber editar: copia el prompt, pégalo en la herramienta, y ajusta si hace falta.

**Formato para todos:** vertical (9:16), 8-15 segundos, con espacio para texto
en pantalla, paleta morado oscuro + dorado (#f4c95d) + fondo estrellado.

## Cómo reutilizar en las 4 plataformas

Sube el mismo vídeo vertical a las 4 sin crear versiones distintas:

| Plataforma | Formato | Nota |
|---|---|---|
| TikTok | 9:16, subtítulos quemados si es posible | Mejor con música de tendencia |
| Instagram Reels | 9:16 | Añade el mismo texto como caption corto |
| Facebook Reels | 9:16 | Se puede republicar automáticamente desde Instagram |
| YouTube Shorts | 9:16, máx. 60s | Añade título con palabra clave (ej: "Tarot prenatal") |

## Ritmo sugerido para empezar (sin publicidad, orgánico)

3 publicaciones por semana, alternando formatos. Después de 2-3 semanas,
mira qué formato tiene más guardados/compartidos (no solo "me gusta") y
repite ese patrón — esa es la señal real de qué está funcionando.
